## Alerta

The [alerta](https://alerta.io) monitoring system is a tool that
collects alerts from multiple sources and removes duplicates, for a quick
‘at-a-glance’ view. With only one system, you can monitor
alerts from many other monitoring tools on a single screen.

**Example:**

| Config | Example |
| ------ | ------- |
| API Endpoint   | http://alerta.example.com/api/alert |
| Apy key | api key with write permission |
| Origin | LibreNMS |
| Environment | Production |
| Alert state | critical |
| Recover state | cleared |
